# Conventions
- Code en anglais, interface en français.
- Git : branche par fonctionnalité (`feature/<module>-<sujet>`), commits courts, une PR courte par changement.
- Messages de commit clairs, langue cohérente.
- Pas de code commenté, pas de TODO sans ticket.
- Nouvelle dépendance : vérifier maintenance, licence, compatibilité Spring Boot 4 / Jakarta EE 11, et le signaler dans la PR.
