# Revue de pull request

## Étapes
1. Vérifier la liste de contrôle de `.github/pull_request_template.md`.
2. Appliquer la compétence `security-review`, puis vérifier les tests et les tests d'architecture.
3. Vérifier que la spécification et `docs/status.md` sont à jour.
4. Résumer : points bloquants, améliorations, décision recommandée.
